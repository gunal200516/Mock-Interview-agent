# Cook'd AI — IBD Career Prep Dashboard

The full Next.js repository lives in the **parent directory** (`/home/z/my-project/`).

See [`../README.md`](../README.md) for the complete project overview, file structure,
setup instructions, and customization guide.

## Quick start

```bash
cd ..            # go to the project root
bun install      # install dependencies
bun run dev      # start dev server on http://localhost:3000
```

## What's in this repository

- **Dashboard route (`/`)** — pixel-close rebuild of the Cook'd AI IBD prep dashboard
- **7 stub routes** — Chat, Learn, Mock Interview, Tracker, Insights, Resume, Networking
- **Mock data layer** — `src/lib/dashboard-data.ts` (edit one file to change everything)
- **Dark theme** — design tokens extracted from the original screenshot

See `../README.md` for the full file map and design token table.
